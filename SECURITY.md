# Reporting security or privacy issues

Please email **rafaeltorresng@gmail.com** with the subject **Rasc security report**.
This is the maintainer's existing feedback address. Do not put private thoughts,
credentials, databases or exploitable details in a public issue.

Include the Rasc version/build, macOS version, a description and minimal synthetic
reproduction steps. Redact personal information. The app's Send Feedback action
can prepare an email, but review its contents before sending.

This project is maintained on a best-effort basis and does not promise a response
SLA. Report suspected data loss, unintended network transmission, stale Refine
acceptance or sandbox violations even if you are unsure of the cause.

Supported fixes target the current source revision. Packaged release support and
signing/notarization status must be checked against the particular artifact's
release notes; source availability alone does not certify a binary.
