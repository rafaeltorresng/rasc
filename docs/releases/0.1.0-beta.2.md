## Summary

Second private beta after M13A app-wide reliability audit, M12C-002 closeout, and M13B RC packaging.

## User-facing capabilities

- Menu bar scratchpad with global shortcut
- Local-first notes with FTS search
- Home history browser
- Refine (on-device via Apple Intelligence when available)
- Settings: global shortcut, Launch at Login, **Refine Language** (M12C-001)
- Onboarding for new users

## Not included

- Global Refine style preferences (M12C-002 rejected and reverted)
- Named tone modes, per-note Refine instructions, cloud Refine

## Known limitations

- Refine requires macOS 26+ and Apple Intelligence on supported hardware
- Ad-hoc signed private beta: Gatekeeper warns on first open; use right-click → Open
- Developer ID signing and notarization **unavailable** on build machine
