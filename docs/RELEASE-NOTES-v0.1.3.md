# Rasc 0.1.3 — Keyboard Shortcuts

Version: 0.1.3 · build 9 · Apple silicon · macOS 14+

- Settings includes Keyboard Shortcuts: Toggle Scratchpad and Toggle Home can be changed, and the other Rasc commands are listed read-only.
- Command Palette opens that settings section. Menus, onboarding, and the scratchpad show the global combination currently in use.
- Internal commands stay fixed. New, Refine, Keep, Search, Escape, and Home behave as before.

This release is ad-hoc signed and **not notarized**. Follow
[the unsigned install guide](INSTALL-UNSIGNED.md) for the first launch.
Refine remains optional and needs macOS 26+ with Apple Intelligence enabled.
