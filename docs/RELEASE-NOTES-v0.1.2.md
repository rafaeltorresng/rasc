# Rasc 0.1.2 — New in the scratchpad header

Version: 0.1.2 · build 8 · Apple silicon · macOS 14+

- The scratchpad header shows New beside Refine and Keep when the note has text.
- New uses the existing Command-N command: the previous thought stays unfinished and the editor is ready to type.
- If the note cannot be saved, the current text stays in place.
- An empty draft does not show New. Escape, Keep, Refine, and Home are unchanged.

This release is ad-hoc signed and **not notarized**. Follow
[the unsigned install guide](INSTALL-UNSIGNED.md) for the first launch.
Refine remains optional and needs macOS 26+ with Apple Intelligence enabled.
