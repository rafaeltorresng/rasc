## Historical material

Product.md remains useful for the product thesis. PRD, UX-Spec, DESIGN-SYSTEM,
ARCHITECTURE, HOME-SPEC, ONBOARDING-SPEC, PRODUCT-STATE and RASC-CONTEXT contain
specification or milestone snapshots. They are reference material, not proof that
all described behavior is current or shipped. Earlier private-beta access/pricing,
old shortcut choices and Breathing Orb recommendations do not govern this revision.

THOUGHT-COMPLETION and its test checklist explain the lifecycle's original design.
APP-RELIABILITY and the Refine milestone documents record past validation. PRIVATE-BETA,
BETA-1-RELEASE-NOTES and RC-MANUAL-TEST describe earlier distribution work; do not
reuse their acceptance records for a new artifact.

[Evals](../Evals/README.md) and Scripts include historical research and engineering
experiments. Generated output is not a current performance claim. Preserve the
history, but distinguish it from current acceptance evidence.
