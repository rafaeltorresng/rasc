# Rasc 0.1.5 — A clearer first run

Version: 0.1.5 · build 11 · Apple silicon · macOS 14+

- First run now tells the product story at the right moment. Live capture teaches only `⌘J` Refine and `Esc`; the Ready screen then maps Keep, Search thoughts, Home, Command Palette and Settings with plain-language descriptions and your live shortcuts.
- The Ready screen states plainly that Refine is optional and that everything above works without it.
- Step reveals use a short stagger and collapse to a quick fade when Reduce Motion is enabled.
- After at least three notes and a second Home visit, Home shows a one-time, dismissible tip that `⌘P` searches from anywhere. Existing installs never see a forced tour or tip.
- Home disables Duplicate for notes without content instead of reporting a save error.
- Onboarding shows the Refine shortcut you actually configured, not the default.

Upgrading preserves notes, settings and shortcuts. Onboarding does not reappear for existing installs.

This release is ad-hoc signed and **not notarized**. Follow
[the unsigned install guide](INSTALL-UNSIGNED.md) for the first launch.
